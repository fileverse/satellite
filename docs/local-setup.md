# Install the Satellite package

To install the package run
```bash
npm install -g @fileverse/satellite
```
This will install the `fileverse-satellite` package globally on your system. 

To run the package, run the `fileverse-satellite` command on your teminal as shown below.
```bash
fileverse-satellite
```

This will prompt you to provide
- Your API key
- Pimlico API key, and
- RPC_URL

This will start the server on your terminal.
